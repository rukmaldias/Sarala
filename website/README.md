# Sarala documentation site

[Docusaurus](https://docusaurus.io/) rendering layer for the project docs.

**The docs are not here.** They live in the repo alongside the code they
describe and this site sources them in place:

- `../docs/` → the **Design & Roadmap** section
- `../boards/` → the **Boards & Hardware** section (a second docs-plugin instance)

So the docs-as-code property is preserved: edit the Markdown where it lives; this
site just renders it. Sidebars are autogenerated, so new `.md` files appear
without touching any config.

## Commands

```bash
npm install      # once
npm start        # local dev server with live reload
npm run build    # static build into ./build
npm run serve    # serve the built site locally
```

## Notes

- `.md` files are parsed as **CommonMark** (`markdown.format: 'detect'`), because
  the docs use `<https://…>` autolinks and other angle brackets that MDX would
  misread as JSX.
- `onBrokenLinks` is set to `warn`: some docs cross-link with repo-relative
  paths that are correct on GitHub but that Docusaurus's per-instance checker
  can't resolve across the two docs instances.
